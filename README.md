# Family Chart

A simple phone-friendly weekly family check chart.

- Add family names
- Add charts (chores, homework, whatever you track)
- Tap a square for each person / day
- Gold star when everyone is done that day
- Saved on the device (no login)

## Open on your phone

After GitHub Pages is on, the app is here:

**https://dannyfworks-wq.github.io/family-chart/**

In Safari: Share → Add to Home Screen.

## Turn on GitHub Pages

1. Open the repo **Settings** tab
2. **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / folder: `/ (root)`
5. Save

It usually takes a minute the first time.
